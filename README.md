# Drop

Drop یک سامانهٔ Local-first برای ارسال فایل و پوشه میان اعضای یک شبکهٔ داخلی است. برنامه روی ویندوز، مک یا لینوکس اجرا می‌شود و کاربران بدون نصب اپلیکیشن، از مرورگر متصل می‌شوند.

```text
http://drop.local:8088
```

> نسخهٔ `0.6.1` برای شبکهٔ داخلی آماده است. قرار دادن مستقیم آن روی اینترنت توصیه نمی‌شود.

## امکانات

- ثبت‌نام با نام و PIN و تعیین خودکار اولین کاربر به‌عنوان مدیر
- کاربران آنلاین، اعلان لحظه‌ای و ارسال گروهی با یک نسخهٔ ذخیره‌شده
- سه حالت ارسال مستقل: فقط فایل، فقط متن و متن همراه فایل
- پیام متنی ساده تا ۱۰٬۰۰۰ نویسه، بدون عنوان یا گردش وظیفه
- فایل و پوشه با حفظ مسیر، آپلود قطعه‌ای و ادامهٔ ارسال نیمه‌کاره
- حداکثر ۲ گیگابایت برای هر فایل و سقف پیش‌فرض ۱۵ گیگابایت
- دانلود جداگانه یا ZIP استریم‌شونده
- مدیریت نقش، مسدودی، PIN، گزارش رویدادها و مصرف فضا
- حذف توسط فرستنده یا مدیر
- رابط فارسی واکنش‌گرا با فونت آفلاین Vazirmatn
- آدرس mDNS محلی `drop.local` همراه با IP جایگزین

## نیازمندی‌ها

- Node.js 22 یا جدیدتر
- اتصال دستگاه‌ها به یک Wi-Fi/LAN
- خاموش‌بودن Client/AP Isolation مودم
- مجازبودن Node.js در Windows Firewall برای شبکهٔ Private

هیچ پکیج npm یا دیتابیس خارجی لازم نیست.

## اجرای ویندوز

1. پروژه را دانلود یا Clone کنید.
2. روی `start-windows.cmd` دوبار کلیک کنید.
3. Launcher تنظیمات را می‌سازد، IP را نمایش می‌دهد و مرورگر را باز می‌کند.
4. پنجره را باز نگه دارید؛ برای توقف `Ctrl+C` بزنید.

## اجرای macOS

```bash
chmod +x start-mac.command
./start-mac.command
```

## اجرای دستی

```bash
cp config.example.json config.json
node server.mjs
```

سپس `http://localhost:8088` یا `http://drop.local:8088` را باز کنید.

## تنظیمات

`config.json` در اولین اجرا از روی نمونه ساخته می‌شود:

```json
{
  "port": 8088,
  "host": "0.0.0.0",
  "localName": "drop",
  "dataDirectory": "./data",
  "storageLimitBytes": 16106127360,
  "reserveBytes": 1073741824,
  "maxFileBytes": 2147483648,
  "registrationCode": ""
}
```

`config.json` و پوشهٔ `data` عمداً وارد Git نمی‌شوند.

## معماری

```text
Drop
├── launcher.mjs       # اجرای آسان و نمایش آدرس شبکه
├── server.mjs         # HTTP API، احراز هویت، SQLite و فایل‌ها
├── local-name.mjs     # معرفی drop.local روی mDNS
├── lib.mjs            # اعتبارسنجی و ابزارهای امنیتی
├── public/            # رابط فارسی و فونت آفلاین
├── test/              # تست‌های Node
└── data/              # دیتابیس و فایل‌های واقعی؛ خارج از Git
```

## Backup

سرور را متوقف و پوشهٔ `data` و فایل `config.json` را کامل کپی کنید. برای بازیابی، همین دو مورد را به پوشهٔ برنامه برگردانید.

## تست

```bash
node --test
```

## امنیت

- PINها با `scrypt` و Salt تصادفی ذخیره می‌شوند.
- نشست‌ها HttpOnly و SameSite=Strict هستند.
- ثبت‌نام فقط از IP خصوصی پذیرفته می‌شود.
- نام فایل روی دیسک تصادفی است.

برای دسترسی اینترنتی ابتدا HTTPS، احراز هویت قوی‌تر، Rate Limit، CSRF Protection، اسکن فایل و Reverse Proxy یا VPN اضافه کنید. جزئیات در [SECURITY.md](SECURITY.md) است.

## محدودیت‌ها

- `.local` به multicast شبکه وابسته است؛ IP مسیر جایگزین است.
- برای ادامهٔ آپلود، همان فایل یا پوشه باید دوباره انتخاب شود.
- ZIP بدون فشرده‌سازی حجمی استریم می‌شود تا RAM و فضای موقت مصرف نکند.
- نسخهٔ فعلی برای انتشار مستقیم اینترنتی سخت‌سازی نشده است.
